# String

## What is a String?

`std::string` is a class from the C++ Standard Template Library (STL) 
used to work with **text**. Unlike C-style char arrays, `string` handles 
memory automatically and provides many useful functions.

Think of it as a flexible text container that can grow, shrink, 
and be modified easily.

---

## Why Use It?

- When you work with **text** (names, sentences, etc.)
- When you need to **search, replace, or modify** text
- When you need to **concatenate** strings (`+`)
- When you want to use **STL string functions** (`find`, `substr`, ...)
- When you need **safe** string operations (no memory issues)
