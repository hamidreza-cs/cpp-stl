# C++ STL

👋 **About This Repository**

A collection of examples and exercises for learning the C++ Standard 
Template Library (STL). Covers containers, algorithms, iterators, 
and practical usage.

**Level:** Beginner to Intermediate  
**Code:** VS Code + MinGW g++

---

## 📚 Topics Covered

- **Containers:** vector, string, array, stack, queue, deque, set, map
- **Unordered:** unordered_set, unordered_map
- **Algorithms:** sort, search, modify, numeric
- **Utilities:** pair, tuple, iterators
- **Practice:** real-world examples
